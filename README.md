## Быстрый старт

**Из исходников:**

```bash
git clone https://github.com/Dimitrov1985/girl-agent.git
cd girl-agent
npm install
npm run dev
```

Wizard задаст вопросы — Telegram-подключение, LLM-провайдер, имя, возраст, голос (TTS), генерация фото. Всё.

Если профиль уже есть:

```bash
npm run dev -- --profile=arina
```

С веб-дашбордом:

```bash
npm run dev -- --profile=arina --web=3000
# Открыть: http://localhost:3000
```

## Возможности

### Поведение

- **Не всегда онлайн** — паттерн присутствия зависит от персонажа: кто-то в телефоне круглые сутки, кто-то заходит раз в час
- **Ночью спит** — можно разбудить через `:wake`, без команды шанс ответа низкий
- **Расписание дня** — пары, работа, дорога, свободное время. Если на занятиях — телефон недоступен
- **Гормональный цикл** — влияет на настроение и раздражительность, биохимически обоснован
- **Проактивные сообщения** — сама пишет первой: поздравляет, интересуется как прошло, напоминает о событиях

### Отношения

- **Пять счётчиков** — interest, trust, attraction, annoyance, cringe. Меняются от каждого диалога
- **Стадии сближения** — от "дала тг, но холодная" до "давно вместе". 8 стадий, каждая меняет тон и поведение
- **Конфликты** — если давить, спамить или нарушать границы — включается конфликт. Может замолчать на часы или дни
- **Приватность** — режим `owner-only`: отвечает только тебе, игнорирует всех остальных

### Память

- **Long-term memory** — важные события пишутся в markdown-файлы и всплывают в будущих диалогах
- **Daily summaries** — по итогам дня генерируется сводка, используется для поиска по прошлым темам
- **Realism context** — факты о собеседнике, привычки, социальный граф, открытые вопросы
- **История между перезапусками** — при рестарте восстанавливает контекст из последней сессии

### Медиа

- **Голосовые сообщения** — через OpenAI TTS (`nova`, `shimmer` и другие голоса) или ElevenLabs. LLM генерирует речь, не текст
- **Генерация фото** — selfie через DALL-E 3 или Stability AI. Внешность описывается при создании и используется для всех фото. Контекст берётся из расписания (дома, в кафе, на улице)

### Контекст

- **Погода** — текущая погода в её городе через open-meteo.com (бесплатно, без ключа). Влияет на настроение и активность
- **Календарь** — события добавляются через `:cal add`, используются в расписании и агенде

### Anti-AI

Промпт запрещает: markdown, "конечно", "я понимаю", эмодзи-ряды, вопросы в конце, "хочу сказать", "полагаю что" и всё, что мгновенно выдаёт ChatGPT.

### Userbot mode

Настоящий Telegram-аккаунт через MTProto. Умеет читать сообщения, ставить реакции, печатать, удалять, редактировать. Выглядит как живой человек.

## Команды дашборда

```
:status                          — состояние, стадия, счётчики
:relationship                    — подробные метрики отношений
:persona                         — содержимое persona.md
:log [YYYY-MM-DD]                — лог переписки за день

:stage <id>                      — сменить стадию отношений
:reset                           — сбросить отношения
:wake [chatId]                   — разбудить (форсировать онлайн)
:pause / :resume                 — пауза и возобновление

:edit persona <что изменить>     — обновить персону через LLM
:edit speech [что изменить]      — обновить стиль речи
:edit vibe normal|cute|alt|clingy|chatty  — сменить пресет общения
:edit stage <id>                 — алиас для :stage
:edit appearance [описание]      — обновить внешность

:appearance                      — сгенерировать appearance.md из persona.md
:appearance show                 — показать текущее описание внешности
:appearance preview              — тестовое фото в Telegram (нужен imagegen)

:privacy [open|owner-only]       — настройки приватности

:cal list                        — список событий календаря
:cal add YYYY-MM-DD [HH:MM] название  — добавить событие
:cal del <id>                    — удалить событие

:amnesia <мин> [chatId]          — удалить историю за N минут
:why [chatId]                    — почему последнее решение было таким
:debug [chatId]                  — debug-снимок состояния

:block / :unblock [chatId]       — блокировка (userbot)
:read [chatId]                   — пометить прочитанным (userbot)
:delete-last [chatId]            — удалить последнее сообщение
:edit-last <текст>               — редактировать последнее сообщение
:sticker [chatId]                — отправить стикер

:quit                            — остановить агента
```

## Веб-дашборд

```bash
npm run dev -- --profile=arina --web=3000
# или с паролем:
npm run dev -- --profile=arina --web=3000 --web-token=секрет
```

Открыть: `http://localhost:3000`

**Что есть:**
- **Лог** — real-time события: входящие/исходящие сообщения, ошибки, инфо. Поле для команд прямо в браузере
- **Память** — просмотр `persona.md`, `speech.md`, `long-term.md`, `appearance.md`
- **История** — логи переписки по дням
- **Календарь** — события добавленные через `:cal add`
- **Графики** — interest, trust, attraction, annoyance, cringe обновляются в реальном времени

## Docker

**Запуск на сервере:**

```bash
# 1. Создай профиль локально
npm run dev

# 2. Скопируй data/ на сервер
scp -r ./data user@server:/opt/girl-agent/

# 3. На сервере
git clone https://github.com/Dimitrov1985/girl-agent
cd girl-agent

# 4. Настройки в .env
echo "GIRL_AGENT_PROFILE=arina" > .env
echo "GIRL_AGENT_WEB_TOKEN=секрет" >> .env

# 5. Запуск
docker compose up -d

# Логи
docker compose logs -f

# Веб-дашборд
# http://ваш-сервер:3000/?token=секрет
```

Бот перезапускается после ребута (`restart: unless-stopped`). Логи ротируются автоматически.

## Безопасность

⚠️ **Не публикуй:** `data/`, `config.json`, `sessionString` и API-ключи.

🔒 **Для userbot mode** используй отдельный тестовый аккаунт — Telegram может забанить основной аккаунт за подозрительную активность.

🔐 **Веб-дашборд** — всегда используй `--web-token` если сервер доступен из интернета.
